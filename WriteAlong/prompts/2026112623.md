
Write Along
===========

A word processor that combines the simplicity of markdown with beautiful templates

File format
============

It is a directory with the suffix .wa with the following contents

- content.md
    - contains all the content
    - Strict Github flavored markdown
- style.css
    - contains all the formatting information
    - page size, color, font, font size, background color, poisition of all the elements
    - use a simple naming convention people familiar web development or not alike can make changes and build their own template
- images/
    - subdirectory with all the images embedded
- read.html
    - static web application with version noted
    - when served from the directory displays a beautiful document in any modern web browser
    - no toolbar or features, browser controls are sufficient
    - preview in html and print-to-pdf from browser should be identical
- syntax.md
    - detailed syntax description file AI agents can refer to and help users edit existing or build new templates

The file format shoud lend itself to editing in the dedicated write along editor or just editing the content.md and style.css directly in any text or code editor

Editor
======

- Static web application that loads the directory with .wa extension
- logo looks like WA in a beautiful font with the last stroke of W and first stroke of A are common and overlapping \/\/-\ but in more beautiful font
- has edit, and read modes
- edit mode, split view with content.md and style.css editing on the left and live view of read.html on the right
- read mode, hides the content.md and style.css editing options and centers the live view of read.html
- menu options and tool bar comparable to common word processors
- allow export as pdf, standalone html file
- contains at least a 100 different latex like beautiful templates, these are the corner stone of the application, pick a variety of popular document types and lots of different beautiful template options
- each template should at least have three pages of content
- user should be able to preview the template with intended content or just apply the style to their own
- have the templates be just .wa directories, so I can access them easily as well outside of the editor
- works offline and only loads the assets from server on first load and when the editor is updated
- supports dark/light mode based on system preference, in dark mode the html preview is dimmed since it is white
- Write a robust syntax guide that shows off how to use the application, introduces all the github flavored markdown syntax, style.css syntax to the user and have it conveniently accessible through one of the menu options
